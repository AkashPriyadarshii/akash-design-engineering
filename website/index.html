The 5 Pillars of Design Engineering

Extracted from the top 267 UI engineering skills, these are the immutable physical frontend laws mandated by the akash-design-engineering engine.

Pillar I

Geometry

Arbitrary corner radii are banned. Radii must follow strict concentric geometry mathematics. 1px Swiss subgrid layouts mandate severe macro-whitespace for cinematic pacing.

Pillar II

Pigments

OKLCH formulations dictate color generation. Anchor-chroma gray bleeds ensure cohesive neutral foundations. Complete rejection of standard industry palettes in favor of specific visual identities.

Pillar III

Physics

Interaction feedback is hard-capped under 200ms. Analytical RK4 ODE Kinetic Springs calculate physical motion. Default CSS transitions are replaced with custom cubic-bezier curves.

Pillar IV

Shaders

Integration of WebGL techniques. Liquid glass rendering, Bayer dithering, and 120 FPS camera projection ensure performance without visual tearing or frame drops.

Pillar V

Sensory

Procedural mechanical clicks using Web Audio API and deep integration with native Android HapticEngine waveforms provide an unparalleled tactile digital interface.

3 Modes

The command palette of the design-engineer skill.

New Mode

Build Fresh Bespoke Systems

Scaffolds an entirely fresh, high-craft interface enforcing the 5 pillars. Applies concentric math, OKLCH pigments, analytic RK4 ODE kinetic springs, and FLIP layout engines from absolute zero.

/design-engineer audit

Audit Mode

Cold 10-Dimension Scorecard

Executes a cold, mechanical audit checklist to identify and flag template anomalies. Detects banned fonts, pure black/white voids, unauthorized entrance animations, and arbitrary inner radii. Generates a strict pass/fail 0-100% score.

/design-engineer refit

Refit Mode

Surgical Code Correction

Refactors existing templates into high-craft design engineering. Surgically replaces CSS defaults with specific custom cubic-beziers. Fixes concentric radii math, injects tabular-nums, and adds procedural audio micro-clicks.
